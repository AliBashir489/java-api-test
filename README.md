Bookshop API
Technologies Used: Java, Spring Boot, MySQL, RESTful APIs, HTML, GitHub

The Bookshop API is a robust backend service built using Java and the Spring Boot framework. It serves as a data-driven application with secure user management and personalized book search functionality. The API integrates MySQL for efficient relational database management, ensuring high performance in data retrieval and storage.

Key Features:

User Authentication: Secure account creation with encryption for protected user data.
Personalized Book Search: Advanced filtering options based on book name, genre, and other attributes.
Wishlist Feature: Users can dynamically manage their personal collection of books, utilizing efficient CRUD operations for seamless interaction.
This project showcases a RESTful API architecture designed for scalability, performance, and usability, making it a versatile solution for managing book data in an e-commerce or library application.
